## Composition

- Masthead variants: profile, earnings, payment, cashback-status, home, offers. The home variant has size default (tall hero) and compact (header row and SearchBar only).
- Home reuses HomeHeader and SearchBar. Offers reuses SearchBar and OffersCategoryStrip. Profile reuses Button. Cashback-status reuses StatusBadge and BrandLogo.
- OffersCategoryStrip is exported so the Offers screen can pin it as a sticky header while the search row scrolls away.
- CardDetailMasthead gets its progress from the parent sheet (gorhom animatedIndex). The parent also drives the sheet body from the same value.
- EligibilityMasthead variants map to the three result sheets: EligibleSheet, MaybeSheet and IneligibleSheet.
