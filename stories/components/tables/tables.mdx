## Composition

- `CompareTable` takes `selectedColumnId` and `onSelectColumn` from the screen. Tapping the selected header clears it. Without `onSelectColumn` the headers do not respond.
- The hero cell is a slot. The table gives it a fixed 146 by 172 box and does not pad it, so the content sets its own padding.
- Row height follows the hero height, so a value cell is 172 high and not the Figma 88. This was inferred, not read from the file.
- `BreakdownTable` sums the rows in paise. Pass `total` only when the screen has its own net rule.
- Negative values are costs. Show a fee as a negative number and the total stays correct.
- Higher total wins unless `lowerIsBetter`. Use `lowerIsBetter` for fee only tables.
