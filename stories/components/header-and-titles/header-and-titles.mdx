## Composition

- Header with `tabs` renders TabPrimary below the row. See Tab bar.
- HomeHeader scrolled=false sits over the dark masthead (logo is the white-tone SVG). scrolled=true is a gradient from cobalt-100, no real blur, so web and native match. It shows the dark logo, search and filter chips.
- MastheadHeader has no background. iconType follows the surface below it: solid for light (white fill, soft shadow), overlay for dark or image (black fill, 1 px white border).
- No back or close SVG ships in `src/assets/icons`, so the glyphs are drawn inline. When artwork lands, swap each glyph for an Icon.
