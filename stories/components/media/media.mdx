## Composition

- All three logo frames take a `source` from the image registry (`src/assets/images`). Brand tiles are in `images.brands`, store and partner art in `images.stores`.
- Only `BrandLogo` goes through `RemoteImage`, which retries once on the other CashKaro asset host. `LogoContainer` and `BrandLogoTile` use the plain RN `Image`.
- The header of `BrandLogoTile` says the image fills the box. The code uses `contain` with padding, because brand logos carry transparent margins. Trust the code.
- `CardArt` is shared by the card detail masthead and the floating rail so a crossfade between them lines up. Only the active card tilts. Neighbours pass `tilt={false}`.
- `Icon` comes from one registry. Add a new icon in `src/assets/icons` and in the `Icon` registry, not as an inline SVG, except where the existing code already draws one (`InfoCircleGlyph`).
