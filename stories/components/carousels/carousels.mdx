## Composition

- All seven `Carousels` exports use a horizontal ScrollView, so any item count fits without truncation.
- `PromoBanner` and `BestForSpending` own an `Indicator`. `PromoBanner` shows it only with two or more slides. `BestForSpending` feeds the scroll variant from the live scroll position.
- `CardCarousel` wraps the organism `CardTile`. The Cards family page explains which card tile to pick.
- `CrossSellRail` is presentation only. The engine and the open rules are in `src/lib/crossSell.ts` and `src/screens/useCrossSellRail.ts`. Each pick is a `CompareCard` molecule, not a `CardTile`, because a `CardTile` cannot compare two cards.
- `ToolsRow` rotates two words on one shared timer. It runs only while the screen has focus and stops under reduced motion. `HomeSkeleton` reserves its height with `TOOLS_ROW_FIT_H`.
- `CategoryCircle` has no user today. Do not start a new row with it before design says which category visual wins.
- Dimensions that are not on the spacing scale (150, 92, 108, 326, 72, 258, 166) are named file constants in `Carousels.tsx`.
