## Composition

- None of the three uses a chart library. They are Views with computed widths from `src/lib/chartMath.ts` and `src/lib/podium.ts`.
- `StackedBar` keeps a gap between segments because neighbouring series colours are under 3:1 contrast against each other. Every segment is in the legend.
- `PodiumCompare` reserves the card art overhang above each bar so the art never covers the value. It declares no winner on a tie or when both values are 0 or less.
- `BarBreakdown` and `StackedBar` appear only in the DS additions gallery today. Only `PodiumCompare` is on a screen (Beat my card result).
- The ranked list does not sort by value in `PodiumCompare`. The caller decides which card is A and which is B.
