## Composition

- `Skeleton`, `AmountSkeleton` and `HomeSkeleton` each run their own copy of the same pulse. `AmountSkeleton` and `HomeSkeleton` were not moved onto `Skeleton`.
- `HomeSkeleton` needs a SafeArea provider for the top inset. It also sets dark status bar icons while it shows. The Storybook preview already provides both.
- `FilterTransitionOverlay` draws `HomeSkeleton` behind the cat animation, so the page reads as reloading underneath.
- Pattern rule: skeleton first, a wait line for long calls (tools), and no spinner on money values.
- Open question: with no network `useCards` never resolves, so `HomeSkeleton` stays up. A timeout and a retry belong to the screen, not to the skeleton.
