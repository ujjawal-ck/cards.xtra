## Which one

| You are showing | Use |
|---|---|
| Any copy | `Text` with a `variant` |
| A highlighted phrase with a gradient fill | `GradientText` |
| The Earnings headline that rolls in | `RollingAmount` |
| A figure compared with another ("₹590, ₹2,360 less") | `StatDelta` |
| A time left, or a fixed update date | `Timer` |

The other four parts use Text inside:

| Part | Typography | Colour |
|---|---|---|
| `GradientText` | any `variant` | a named gradient (`gradients.reward`, `gradients.primary` ...) |
| `RollingAmount` | `display36ExtraBold` default | `colors.text.inverse` default (for a dark surface) |
| `StatDelta` | value `body14SemiBold`, label `body12Regular`, delta `body12SemiBold` | `feedback.success.text`, `feedback.error.text` or `text.secondary` |
| `Timer` | `body12SemiBold` | `colors.tones.error.text`, fill `tones.error.bgSubtle`, border `tones.error.border` |

## Composition

- Never set font size, family, weight or line height by hand. Use a `variant`, or add one to `src/tokens/typography.ts`.
- Text follows the OS font size with no cap. Components grow (minHeight, wrap) instead of clipping.
- Format money with `formatINR` (Indian grouping: ₹1,00,000). `StatDelta` does this for a numeric `value`.
- `StatDelta` states direction with an icon and a word, never colour alone.
- `RollingAmount`: pass a `playToken` that changes to replay the roll. Do not use it for a value that changes often.
- `Timer` ticks every second only when `targetTime` is set; otherwise it shows the numbers you pass.
- Web: `GradientText` and `RollingAmount` use a masked view and reanimated. They may render blank or static on web. See the story notes; check on a device.
