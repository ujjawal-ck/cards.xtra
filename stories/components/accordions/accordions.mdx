## Composition

- The whole header is one pressable. A tap calls `onToggle(!expanded)`. The part does not keep its own state, so the screen owns `expanded`.
- Stack rows in a plain column. The part has no divider, so add a `Divider` between rows or use `state="bare"` inside a bordered card.
- `highlight` marks one row (for example the open question). Do not highlight more than one row in a list.
- The part is `width: 100%`. Give its parent a width.
