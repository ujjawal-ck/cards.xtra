## Composition

- `StaggeredEntrance` uses `useIsFocused`, so any story or screen using it needs a navigator. `RootNavigator` wraps every pushed screen in it (rise 14, 340 ms, replays on focus). Earnings, Offers and Profile use it for their sections.
- It animates on iOS only. On Android and on web it renders the children plain, keeping `fill` and `style`. This repo keeps Reanimated entrances to iOS because of recurring Android edge-to-edge jank.
- `FilterTransitionOverlay` is mounted by `HomeScreen`. It fires `onCovered` when fully opaque (commit the filters behind it) and `onHidden` after the fade out (set `visible` back to false).
- The cat animation needs the `rive-react-native` native module. Storybook replaces it with an empty view, so the animation itself is not shown here.
- Neither piece checks the OS reduce motion setting. `ToolsRow` does. Open question for product and engineering: should these two follow it?
