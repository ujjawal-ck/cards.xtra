## Composition

- `AmountInput` is an `Input` with `leadingText="₹"` plus a row of `Chip` presets. It formats live with Indian grouping (`1,20,000`) and holds the value at `max` while the user types.
- `OtpInput` draws its own slots (56 by 64 for 4 digits, 48 by 64 for 6). It does not use `OtpBox`. One hidden text field takes all digits.
- `SpendCard` picks a value on a ruler (snap scroll). Its typed entry mode is optional and off by default.
- `SearchBar` shows a results list under the bar only in the `filled` state. `SearchResults` is the same list, for a parent that scrolls it by itself.
- Inside a gorhom bottom sheet, set `useBottomSheetInput` on `Input`, `OtpInput`, `AmountInput` and `SpendCard`, or the sheet will not lift above the keyboard.
- Login and withdraw keep 6 OTP digits (D19). Figma shows 4; the Figma file must change.
