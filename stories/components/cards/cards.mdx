## Composition

- `CardTile (organism)` is built from `CashbackBadge`, `Tag`, `Icon` and `CardFeeStrip`. The `scrollable` type drops the invite pill and the fee strip. Carousels use it.
- `CompareCard` is a `GainBand` on top of art, a name and two `StatDelta` rows. The caller shortens the name (without "Credit Card").
- `RankedCardRow` and `LeagueCardRow` both start with `RankBadge`, then art at 64 wide with the same 132:84 ratio. A ranked row takes a number the screen computed. A league row computes its own sum with `rowSum`.
- `LeagueCardRow` is memoised. Pass stable `row`, `columns`, `tops` and callbacks. A row without an app card has no Apply.
- `CardModel` comes from `src/molecules/CardTile.tsx`. The organism does not take a `CardModel`: the screen maps its fields to props.
- `PaymentRecordCard` is `ListRow` rows split by `Divider`. The header comment suggests a generic List part.
- Hidden parts (`PaymentRecordCard`, `ReviewCard`) stay in the tree for reference. Do not link them from a live screen (D4, D14).
