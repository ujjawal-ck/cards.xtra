## Variant and tone

| Variant | main | second | accent |
|---|---|---|---|
| `solid` | Saffron fill (`action.primary.default`) | Saffron fill (same as main) | Cobalt fill (`action.accent.default`) |
| `outline` | Saffron outline (`action.primary.border`, label `action.primary.hover`) | Cobalt-grey outline (`action.secondary.border`) | not used |
| `subtle` | `action.secondary.default` fill | same | same |
| `destructive` | `action.destructive.default` fill | same | same |
| `ghost` | transparent, white label, `border.inverse` | same | same |
| `link` | no box, `text.link`, underlined | same | same |

Only `solid` and `outline` read `tone`. Every other variant ignores it.

## Composition

- A `Button` is a single atom. It holds a label and at most one icon. It never holds another component.
- Pair at most one `solid` button with outline or link buttons in a row. Two solid Saffron buttons side by side have no hierarchy.
- `icon="only"` still needs `label`: it becomes the accessibility label.
- Pressed state is a Pressable state and has no static prop. Disabled and loading block `onPress`.
- Haptic: `medium` for solid, `light` for the rest. Pass `haptic="none"` to silence it.
- For a sticky bottom bar use `FooterButtons`. It is built from `Button`.
