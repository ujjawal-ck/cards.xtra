## Composition

- `ScreenState` replaces the old one-line texts ("No orders yet.", "Couldn't load offers. Pull to retry.") that each screen styled differently and that gave no way forward.
- Error copy pairs one short title with a body and a Try again action. Empty copy states the reason and, where one exists, points to the next step (for example Explore cards).
- Screens that need account data show `GuestPrompt` for guests instead of empty figures (Earnings, Profile). Login is optional elsewhere: Home, cards and Offers work as a guest.
- Patterns: Empty, Error and retry, and Guest gate pages link here. This page does not repeat their rules.
- Known gap (risk R6): a paused query is neither loading nor error, so Home, Earnings, Offers and Orders fall through to their empty layout while the phone is offline. No offline `ScreenState` exists yet.
