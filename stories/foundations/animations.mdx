## Animation files

These files are in `src/assets/animations`. **They render empty in this Storybook**: Lottie and Rive have web stubs here, so a story shows an empty box. Check them on a device or simulator.

| File | Kind | Used for |
|---|---|---|
| `splash-animation.json` | Lottie | Splash screen |
| `onboarding-1.json`, `onboarding-2.json`, `onboarding-3.json` | Lottie | Onboarding slides |
| `cat-redirecting.riv` | Rive | Filter transition overlay (the cat) |
