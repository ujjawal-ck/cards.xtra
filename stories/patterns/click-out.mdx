## The rule

- One hook handles every click-out: `src/lib/useClickOut.tsx` (D13). Every click logs `click_out`.
- Signed out: the "Log in to earn cashback" sheet, with "continue without cashback". A guest is never blocked.
- Signed in: the app resolves the CashKaro user id first. If it cannot, it does not open an unattributed link.
- The CTA is a solid Saffron button (D17).
- Not built, and the biggest gap: no feedback while the id resolves (the tap looks dead), no hand-off step before the bank or store opens (R8), no state when the user returns (R1), and an empty URL does nothing (R3).
- Attribution is the lifeblood: any change here is a P0 risk by default.
