## The rule

- Use `ScreenState` for every empty and no-results screen. One block, not an ad-hoc line of text (`src/organisms/ScreenState.tsx:23`).
- The title says what is missing. The body says how it fills, or what to change. One optional action.
- "No results" because of filters gets "Clear filters". "No results" because of what the user typed gets "Change my details".
- Empty for a reason the user cannot fix (for example Notifications) has no action.
- Never use an empty state for "I do not know yet". Offline with no cache and a failed fetch look empty in code today (audit, systemic finding). Show the Offline or Error pattern instead.
- Only three illustrations exist: `appOrders`, `tracking`, `confirmation`.

## Where it appears

- Flow 2 Home and discovery: Home no match (with closest cards), Offers empty, Search no results.
- Flow 3a and 3b: Cards you can get (no cards, filters match nothing).
- Flow 5 Card advisor: Results (no cards fit), catalogue empty.
- Flow 7 Earnings and withdraw: transactions per filter.
- Flow 8 Orders and missing cashback: Orders (no orders, no match), Claims per tab.
- Flow 9 Profile and account: Notifications (always empty).
