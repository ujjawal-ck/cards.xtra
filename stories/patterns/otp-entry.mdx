## The rule

- Six digits, because CashKaro production sends six (D19). Figma still draws four.
- The resend control has three states: hidden while verifying, a countdown, then "ready".
- A wrong or expired code sets `state="error"` and a short hint: "Enter a valid OTP" or "OTP is expired" (`src/screens/withdraw/WithdrawVerifyOTP.tsx:211`).
- While the code is being verified or the payment is being made, the input is blocked (`WithdrawVerifyOTP.tsx:297`).
- Open risk (R20): the rate limit (5 per number, 10 per IP in 10 minutes) shows the raw API message with no time to retry. The audit has no copy for it, so none is shown here.
- Edit contact and Delete account accept any six digits today (R5). They are demos.

## Where it appears

- Flow 1 Launch and login: Login sheet (OTP, wrong OTP, resend, rate limit not built).
- Flow 7 Earnings and withdraw: Details, Verify OTP (entry, wrong, resend, connection problem, payment failed, unknown outcome, session expired).
- Flow 9 Profile and account: Edit contact (demo), Delete account (hidden, demo).
