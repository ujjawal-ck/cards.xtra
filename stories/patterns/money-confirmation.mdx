  A money step never leaves the user guessing. If the outcome is unknown, do not let them submit again.
</PageHeader>

## The rule

- A payout already in process blocks a second request: Withdraw opens `PaymentProcessingSheet` instead (`src/screens/withdraw/useWithdrawGate.tsx:126`).
- An unknown outcome (a timeout after the send) must tell the user not to request again until it shows in Earnings. Today it is a native Alert (`WithdrawVerifyOTP.tsx:89`).
- A failed payout needs an error that stays on screen, not an Alert that vanishes (`WithdrawVerifyOTP.tsx:177`).
- Success goes to Home with no swipe back and no per-payout record yet (R4). Payment History is hidden (D4).
- Never show ₹0 for an amount that is unknown (see Offline).
- The OTP step has its own states: see OTP entry.
