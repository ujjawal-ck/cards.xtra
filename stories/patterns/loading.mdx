## The rule

- Use a skeleton that matches the page: `Skeleton` for a block, `AmountSkeleton` for a money value, `HomeSkeleton` and `CardListSkeleton` for Home.
- A money value never shows a placeholder number such as ₹0 while it loads. Show `AmountSkeleton` (`src/atoms/AmountSkeleton.tsx`).
- For a call that can take a long time, add one wait line above the skeleton rows. The tools say "up to a minute" (`src/screens/tools/ToolResultsScreen.tsx:522`).
- Every skeleton pulses with the same timing: `motion.duration.pulse` (650 ms), opacity between `opacity[16]` and `opacity[40]`.
- A bare spinner is the old way. Orders, Claims, Store page and All card benefits still use one (audit: PARTIAL).
- A paused query is not a loading query: offline with no cache stays "pending" forever. See the Offline pattern.

## Where it appears

- Flow 2 Home and discovery: Home (first load, category filter), Offers tab, Search.
- Flow 3a Card detail and apply: card detail benefits, All card benefits.
- Flow 4 Shared result: League table, Beat my card (the wait line).
- Flow 7 Earnings and withdraw: Earnings amounts, transactions.
- Flow 8 Orders and missing cashback: Orders list, Order detail, Claims list.
