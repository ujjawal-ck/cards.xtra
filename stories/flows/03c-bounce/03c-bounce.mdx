## Flow

```
ENTRY: close a Home-tile card detail with no Apply
  v
Cross-sell rail under the tile   (flag crosssell_rail = "rail" by default; holdout logs nothing)
  lens chips -> up to 3 picks -> "Check what I can get" -> Hide -> "View all cards"
  |-- a pick ------------------> Card detail (3a) -> Apply [MONEY]
  |-- "Check what I can get" --> Eligibility checker (no event)
  |-- "View all cards" --------> Cards you can get (bounce)
  v
Cards you can get (bounce)   copy does not promise eligibility when it is unknown
  |-- tile -> Card detail -> Apply -> click-out [MONEY, AUTH gate]
EXIT: bank page; card detail (3a).
```

States: 7 live, 0 proposed, 0 hidden, 0 demo. Each state is a story; a row links to it. Screen stories use the real app screen with no network (fixtures answer every call); a proposed state is composed from design-system parts and is not in the app.

## Risks

- **R1**: The bank page return gives no record of the click, so a rail pick and an applied card look the same afterwards. Seen in: both steps (see flow 3a, Click-out).
- **R11**: Apply on the bounce page skips Home's eligibility gate. Seen in: Cards you can get (bounce).
- **R3**: A blocked click-out is silent (see flow 3a). Seen in: Cards you can get (bounce).
