## Flow

```
Search sheet: advisor row (empty query or no results)
   |
   v
Chat (Advisor)
   intro -> opener -> reveal (3 cards) -> questions -> tip(s)
        -> eligibility bridge -> form -> likely to qualify / error
        -> end menu: See all N cards | Check which cards I can get | Change an answer | Start over
   |                                   |
   | card tap -> card detail           v
   v                          Results (AdvisorResults): sort, Free cards only
click-out (source: advisor)
```

Stories reset the shared store, cache and fetch mock when they mount, so each step is its own page. Open them from the tables below.

## Risks

- R11 (score 4): Apply from the tools skips the eligibility gate that Home runs. The user sees no verdict. A tool click-out has no gate.
- R6 (score 6): offline cold start. The tool results handle the paused call with "You're offline"; most other screens show a false empty state. The advisor shows "No cards are available right now" when the card list is paused offline (ux-states section 5, missing).
- Consciously not covered: the advisor went back to its first question and closed, seen once (D28, cause unknown).
