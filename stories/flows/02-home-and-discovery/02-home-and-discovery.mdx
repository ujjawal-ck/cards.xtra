Find cards that fit me without knowing card names. The Home tab holds the masthead with search, the tools row, the filter row (Category, Filters, Eligibility toggle) and the card tiles. Auth: guest. No money step on this flow; the tile "Apply Now" starts flow 3a.
</PageHeader>

## Flow

```
ENTRY: Home tab
  v
Home  ---- search bar --------> Search sheet --- result ----> Card detail (3a)
  |                                  |-- "help me pick" ---> Advisor (flow 5)
  |-- Filters chip --> Filters sheet --> Apply Filter --> white transition --> filtered list
  |-- Eligibility toggle --> Eligibility checker --> result sheet --> Home regrouped
  |                                       (Eligible / Maybe / Ineligible)
  |-- tools row ------------> Tools (flow 4)
  |-- tile tap / "Apply Now" -> Card detail (3a)        [Apply gate and click-out: 3a, MONEY]
  |-- bell -----------------> Notifications (always empty)
  |-- help icon ------------> Get Help (flow 9)
```

States: 18 live, 3 proposed, 0 hidden, 0 demo. Each state is a story; a row links to it. Screen stories use the real app screen with no network (fixtures answer every call); a proposed state is composed from design-system parts and is not in the app.

## Risks

- **R6**: Offline cold start: Home shows the timed skeleton, then no cards and no message. Seen in: Home, offline today.
- **R19**: Notifications always says "You're all caught up"; the bell suggests a feature that does not exist. Seen in: Notifications.

## Open questions

- Home offline with a cached list: keep showing the stale cards or show the offline state? Owner: product owner.
- Empty catalogue (200 with 0 cards): a real case, or always a backend fault that should read as an error? Owner: product owner with the BankKaro team.
- Search with the catalogue not loaded: block the search bar offline, or show a message in the result area? Owner: product owner.
- Hide the Notifications bell until an API exists? Owner: product owner.

Not storied: Home states that need a long tap path beyond the stories (inline filter questions, NeverMissCashbackNudge on Android). Search stories render the real sheet with props; they do not tap the search bar.
