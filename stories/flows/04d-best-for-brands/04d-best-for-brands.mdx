## Flow

```
Home tools row (tile with the rotating brand word)
   |  brandId optional
   v
Brand pick (up to 5)  ->  Spends (one monthly amount per brand)  ->  Results (ToolResults, tool: brands)
   |                                                                       |
   +-- limit reached: info message, other tiles disabled       Breakdown sheet -> click-out
Brand runs are not saved to the device.
```

## Risks

- R7 (score 6): the top rows of the league can be cards the app cannot sell, with no Apply and no card page. Decision D27 is directional.
- R11 (score 4): Apply from the tools skips the eligibility gate that Home runs. The user sees no verdict. A tool click-out has no gate.
- Brands other than Amazon and Flipkart are counted in a category, so a result can differ from the real brand rate. The screen states it; no state shows the difference (product requirement, not ranked).

## Open questions

- League table scope (D27, directional): keep showing cards the app cannot sell, loss-making and discontinued cards, with Apply only in the breakdown sheet? Owner: product owner.
- Should Apply from the tools run the same eligibility gate as Home? Owner: product owner.
- Brand tiles are text only (no brand logos exist). Design gap. Owner: design.
