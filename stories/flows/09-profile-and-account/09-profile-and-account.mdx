## Flow

```
ENTRY: Profile tab | Home help icon | Earnings "Get Help" | Home bell (Notifications)

Profile ──┬─ Edit Profile ──> Account settings [demo, R5]
          │                      ├─ Email / Mobile ──> Verify identity ──> Enter new ──> Verify new ──┐
          │                      │                       (any 6 digits pass)                          │
          │                      └─ <────────── success message, nothing saved ───────────────────────┘
          │                      └─ Delete account [hidden, R16] ──> Delete OTP ──> Account deleted
          ├─ My Earnings / Withdraw / Missing Cashback ──> Flows 7 and 8 (signed in; guest sees a login prompt)
          ├─ Never miss cashback ──> Android setup steps | iOS notice
          ├─ Get Help ──> topics | guest gate on Missing Cashback ──> login sheet
          ├─ Call Us ──> phone app
          ├─ Privacy policy
          └─ Logout ──> confirm sheet ──> Home as guest

Hidden (nothing links here): Payment history x3 (D4), Review Us, Write Review (D14)
```

## Risks

- R5: Edit Profile and contact change say "saved" but save nothing; any OTP passes. See Account settings and Edit contact.
- R9: new users carry a generated placeholder email, shown masked on Profile. See Profile, "Placeholder email".
- R16: a user who wants to delete the account has no path (entry hidden). See Delete account.
- R19: Notifications always says "You are all caught up". See Notifications.
- R13: Get Help's Missing Cashback topic restarts the intake that a not-tracked claim points to. See Get help.
- R6 and R17: profile offline and session expiry on this tab are in Flow 10.
